# HealthLab Hilfekarten – GitHub Pages

Diese Dateien sind fertig für GitHub Pages.

## Schnellstart
1. Auf GitHub ein neues öffentliches Repository erstellen, z. B. `healthlab-hilfekarten`.
2. Alle Dateien und Ordner aus diesem Paket in das Repository hochladen.
3. Im Repository: Settings → Pages.
4. Unter "Build and deployment" / "Source" die Bereitstellung aus einem Branch wählen.
5. Branch `main`, Ordner `/ (root)` auswählen und speichern.
6. Nach kurzer Zeit erscheint die öffentliche Adresse.

Bei einem Benutzernamen `meinname` und Repository `healthlab-hilfekarten` lauten die Seiten dann:

https://meinname.github.io/healthlab-hilfekarten/datenlabor/
https://meinname.github.io/healthlab-hilfekarten/grafiklabor/
https://meinname.github.io/healthlab-hilfekarten/formellabor/
https://meinname.github.io/healthlab-hilfekarten/bedeutungslabor/
https://meinname.github.io/healthlab-hilfekarten/prueflabor/

Wichtig: `meinname` durch den eigenen GitHub-Benutzernamen ersetzen.
